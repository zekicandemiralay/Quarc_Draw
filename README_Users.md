# Quarc Draw — User Guide

Draw and paint with layers and brushes, sketch vector shapes, write in notebooks with a pen, and mark up PDFs — and, if you
want, keep every drawing in step across your devices.

## Getting started

Drawing works **offline and needs no account**. Install it, open it, start drawing.

- **Quarc Store** (Android and Windows): open Quarc Store and install **Quarc Draw**; updates come from there too.
- **Android:** or install the APK from [Releases](https://github.com/zekicandemiralay/Quarc_Draw/releases/latest)
- **Windows / macOS / Linux:** or install the desktop app from Releases
- **iOS:** open `https://quarcnet0.tail84500c.ts.net:4009` in Safari → Share → **Add to Home Screen**
- **Anything else:** just open that address in a browser (Chrome or Edge can also *Install* it from the address bar)

## Syncing your drawings

Sync needs [Tailscale](https://tailscale.com) installed and connected, and the same account as Quarc Music — it is the same account.

1. **File ▸ Sync settings ▸ Quarc account**
2. Sign in with your username and password — or tap **Continue as …** if you are already signed in to **Quarc Store** on this device (the Android and Windows apps then sign in by themselves).
3. That's it: sync turns on, your drawings appear on every device you sign in on, and changes show up live.

Drawings always save on the device first and work offline; they sync when you are back online. If two devices change the same
drawing, **both versions are kept** (one becomes a "conflict" copy) — nothing is ever lost. Choose **Off** in the sync
settings to keep everything on this device only. You can also sync through any folder (Proton Drive, Dropbox, OneDrive…),
WebDAV or Dropbox instead.

## Saving and exporting

- **Windows / macOS / Linux:** *File ▸ Export* opens the system's "Save as" dialog.
- **Android:** exported files open the share sheet — choose **Save to Files**, Drive, mail…
- **Browser:** an ordinary download.
- Your own drawings are `.qdraw` files; PNG, JPEG, WebP, SVG, PDF, PSD and OpenRaster work too.

## Good to know

- **Android:** folder sync is not available (the system does not allow it); use the Quarc account instead.
- **Pen and touch:** pressure, tilt and the pen's eraser end work wherever the system provides them. *Preferences* has pen-only mode and palm rejection.
- **Keyboard:** `Ctrl+K` opens the command palette; `F1` lists every shortcut.
- **Sign out:** *Sync settings ▸ Sign out* only signs out of Quarc Draw. Your drawings stay on the device.
